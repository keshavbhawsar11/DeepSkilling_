# Account Microservice

## Objective

Create a simple Account Microservice using Spring Boot.

## Endpoint

GET /accounts/{number}

Example

http://localhost:8080/accounts/00987987973432

## Sample Response

{
"number":"00987987973432",
"type":"Savings",
"balance":234343
}

## Technologies

- Spring Boot
- Spring Web
- Maven
- Java 17
