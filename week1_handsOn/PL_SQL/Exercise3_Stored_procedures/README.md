# Exercise 3 - Stored Procedures

## Objective

Implement PL/SQL stored procedures to automate common banking operations.

---

## Scenario 1

Process monthly interest for all savings accounts by adding 1% interest to the account balance.

---

## Scenario 2

Update employee salaries by applying a bonus percentage to employees of a specified department.

---

## Scenario 3

Transfer funds between accounts after validating that the source account has sufficient balance.

---

## Concepts Used

- Stored Procedures
- Parameters
- UPDATE Statement
- IF Condition
- Variables
- SELECT INTO
- COMMIT
- DBMS_OUTPUT.PUT_LINE

---

## Files

- solution.sql

---

## Expected Output

- Savings account balances are updated with monthly interest.
- Employee salaries are increased according to the bonus percentage.
- Funds are successfully transferred when sufficient balance exists.
