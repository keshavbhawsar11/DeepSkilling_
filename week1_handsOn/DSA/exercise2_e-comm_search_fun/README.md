## Scenario

Develop a search functionality for an e-commerce platform using Linear Search and Binary Search.

---

## Objective

Implement Linear Search and Binary Search and compare their performance.

---

## 1. Big O Notation

Big O notation measures the time complexity of an algorithm on the basis of input size and data structures used. It helps in comparing the efficiency of different algorithms.

---


## Best, Average and Worst Case

### Linear Search

- Best Case: O(1)
- Average Case: O(n)
- Worst Case: O(n)

### Binary Search

- Best Case: O(1)
- Average Case: O(log n)
- Worst Case: O(log n)

## Time Complexity

Linear Search : O(n)

Binary Search : O(log n)


## Comparison

## LINEAR SEARCH 
- Linearly iterates to find the target
- Works on unsorted data
- Easy and simple

## Binary Search
- Decides to search left or right from the middle element
- Works only on sorted data
- Difficult when compared to linear search but Faster

---

## Which algorithm is suitable?

Binary Search is more suitable for an e-commerce platform because products are generally stored in sorted or indexed form. It provides much faster search performance for large datasets.
