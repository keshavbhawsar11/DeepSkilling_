# Git Exercise 5 - Clean Up and Push to Remote Repository

## Objective

- Verify the repository is in a clean state.
- List all available branches.
- Pull the latest changes from the remote repository.
- Push local changes to the remote repository.

---

## Commands

### Check Repository Status

```bash
git status
```

### List All Branches

```bash
git branch -a
```

### Switch to Main Branch

```bash
git switch main
```

### Pull Latest Changes

```bash
git pull origin main
```

### Switch Back to Working Branch

```bash
git switch week7_handsOn
```

### Push Local Changes

```bash
git push origin week7_handsOn
```

### Verify Remote

Open the GitHub repository and verify that the latest commits are available.

---

## Expected Outcome

- Repository is in a clean state.
- All local and remote branches are listed.
- Latest changes are pulled successfully.
- Local commits are pushed to the remote repository.
- Changes are visible on GitHub.
