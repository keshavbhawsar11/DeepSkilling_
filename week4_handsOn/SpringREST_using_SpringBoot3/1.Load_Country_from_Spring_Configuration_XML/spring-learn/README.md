# Hands-on 6- Load List of Countries from Spring Configuration XML

## Objective

Load multiple Country objects from an XML configuration file and display them using Spring Core.

## Technologies

- Java 17
- Spring Boot
- Spring Core
- Maven

## Files Created

- Country.java
- country.xml
- SpringLearnApplication.java

## XML Concepts Used

- `<bean>`
- `<property>`
- `<list>`
- `<ref>`

## Output

Displays a list of four countries from the XML configuration.
