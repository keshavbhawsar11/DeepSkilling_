# Hands-on - Hello World RESTful Web Service

## Objective

Create a REST endpoint using Spring Boot that returns "Hello World!!".

## URL

```
GET /hello
```

## Response

```
Hello World!!
```

## Technologies

- Spring Boot
- Spring Web
- Maven
- Java 17

## Controller

HelloController

## Annotation Used

- @RestController
- @GetMapping

## Output

Browser:

```
Hello World!!
```

Postman:

```
Hello World!!
```
